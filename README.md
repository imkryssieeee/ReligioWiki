# ReligioWiki

ReligioWiki is a glassy, Apple-inspired “Wikipedia” for world religions. It highlights origins, beliefs, practices, and regional footprints with smooth transitions, comparison tools, and curated summaries.

## Features
- **Glassy UI** with aurora gradients, glassmorphism cards, and micro-interactions.
- **Search & filter** by family (Abrahamic, Dharmic, East Asian, Indigenous, and more).
- **Historical arcs** timeline plus **comparison table** for texts, practices, and regions.
- **Curated summaries** covering major global traditions with quick badges for texts, practices, and populations.

## Getting started
This is a static site—no build step required.

1. From the project root, start a local server (any static server works):
   - Using Python: `python -m http.server 8000`
   - Using Node: `npx serve .`
2. Open `http://localhost:8000` in your browser.

## Customize
- Add or edit traditions in `script.js` inside the `religions` array (accent colors use CSS gradients).
- Adjust visuals in `styles.css` or tweak layout in `index.html`.
